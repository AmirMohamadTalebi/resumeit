- [x] Worker، ابطال نتیجه و کش، جداسازی حساب/فضا و تب‌ها، خطای قابل بازیابی
- [x] رابط مشاور، بازخورد، اعمال امن، undo و تأیید دقیق متن نمونه
- [x] قالب‌های تک‌صفحه‌ای؛ پروژه در صفحهٔ اصلی و جزئیات در پنجره؛ ۵۲ فایل نمونهٔ فرعی حذف شد
- [x] پیش‌فرض‌های عمومی قابل ویرایش/پاک‌کردن؛ بدون افزودن سابقه و دستاورد شخصی
- [x] بخش‌های کوتاه‌تر، نمایش پایه‌های انتشار و بازشدن بخش در حال ویرایش در پیش‌نمایش
- [x] پیوست تیکت با کنترل نوع، امضا، حجم، مالکیت و نقش؛ سهمیهٔ اشتراک بیشتر
- [x] پاک‌سازی مستقل صفحه با پیامک، کنترل نسخه و جلوگیری از بازاستفادهٔ کد
- [x] سناریوی گوگل از مسیر HTTP واقعی با ارائه‌دهندهٔ مصنوعی
- [x] سناریوی گیت‌هاب، شماره و رمز با ارائه‌دهنده و پیامک مصنوعی

- [x] نسخهٔ ۰٫۲۴٫۰ بتا، صفحهٔ تغییرات و بررسی‌های پیش از پوش آماده شدند

شاهدهای هر مورد و مرز آزمون‌ها در `docs/advisor-release-report.fa.md` ثبت شده‌اند. نتیجهٔ ارسال گیت‌هاب در پیام تحویل اعلام می‌شود.

## موارد وابسته به سرویس واقعی

ورود خارجی و پیامک با حساب/شمارهٔ واقعی و پرداخت بانکی فقط وقتی قابل تأییدند که خود سرویس در محیط آزمایش در دسترس باشد. خرید/حذف روی دادهٔ کاربران واقعی برای تست اجرا نمی‌شود.

- [ ] اتصال واقعی گوگل و گیت‌هاب؛ تنظیمات محلی موجود نبود.
- [ ] ارسال واقعی SMS.ir و پرداخت واقعی زیبال؛ تنظیمات محلی موجود نبود.
- [ ] مهاجرت و آزمون MySQL واقعی؛ اعتبار اتصال در این محیط موجود نبود.

## محدودیت رابط باقی‌مانده

- [ ] سقف سه نمایشگر برای لندینگ عمومی برقرار نیست؛ روایت فعلی و هیرو در این انتشار بازطراحی نشدند. بعضی عرض‌های کوچکِ خانهٔ داشبورد و محصولات مدیر نیز کمی بالاتر از این سقف‌اند؛ جزئیات در گزارش آمده است.
