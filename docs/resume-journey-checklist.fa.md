# مسیر کامل ساخت رزومه

وضعیت: پیاده‌سازی محلی؛ بدون انتشار یا تغییر دادهٔ کاربران زنده.

## مسیر

- [x] پنج مرحلهٔ قابل انتخاب: معرفی، محتوای رزومه، راه ارتباط، ظاهر، مرور و انتشار.
- [x] شروع با نام و عنوان؛ شهر و معرفی کوتاه در جزئیات جمع‌شونده، عکس و امضا در مرحلهٔ ظاهر.
- [x] انتخاب آزاد محتوای واقعی، بدون اجبار به پرکردن همهٔ سوابق یا پیشرفت و امتیاز ساختگی.
- [x] نمایش و ویرایش فقط بخش‌های پشتیبانی‌شدهٔ قالب فعال؛ مسیر پیشرفته باقی است.
- [x] ویرایش مستقیم برای رزومهٔ موجود و پیوندهای قبلی؛ یادآوری حالت و مرحله برای همان حساب و جایگاه.
- [x] گالری تصویری، فونت، رنگ و گردی گوشه در همان مسیر؛ دریافت فقط قالب انتخاب‌شده و رعایت دسترسی خرید/اشتراک.
- [x] مرور واقعی نیازمندی‌ها، نام حساب و انتخاب آدرس در همان صفحه، نمایش خطای تماس و تأیید صریح متن نمونه.
- [x] انتشار از مسیر معتبر قبلی سرور، حفظ کنترل نسخه، ذخیره و حساب؛ بدون انتشار خودکار یا تکرار خودکار درخواست.
- [x] دکمهٔ انتشارِ نوار بالا در حالت ساخت به مرحلهٔ مرور می‌رود؛ در حالت مستقیم، کنترل انتشار قبلی حفظ است.
- [x] راهنمای کیفیت در پایان مسیر و ویرایش مستقیم؛ پیوند پیشنهادها به فیلد یا مورد واقعی و بازکردن جزئیات مرتبط.

## وضوح و پیش‌نمایش

- [x] نام‌های ساختاری بخش‌های ویستا و ساتیار؛ بدون نام شخص نمونه، کد CSS یا متن نمونه به‌عنوان اسم بخش.
- [x] بازشدن بخش انتخابی، رفتن پیش‌نمایش به همان بخش و کادر مشخص دور آن.
- [x] عنوان «در پیش‌نمایش: …» برای تشخیص محل ویرایش؛ این علامت فقط ویرایشگر است، نه نسخهٔ عمومی.
- [x] حفظ موقعیت پیش‌نمایش هنگام نوشتن و حذف علامت بخش هنگام خروج از ویرایش قالب.
- [x] حداکثر چهار فیلد در هر نوبت ویرایش هدایت‌شدهٔ قالب واردشده؛ تمام تنظیمات در حالت مستقیم باقی می‌مانند.
- [x] عنوان واقعی موارد در انتخابگر، حذف انتخابگر تکراری برای یک ردیف و شروع مورد تازه با متن خالی در مسیر هدایت‌شده.
- [x] حرکت کوتاه بین مراحل، فوکوس مشخص، پشتیبانی از کاهش حرکت و چیدمان فشردهٔ موبایل.

## حفاظت

- [x] بدون حذف، مهاجرت یا بازنویسی قرارداد اطلاعات قبلی؛ اطلاعات هر قالب مستقل می‌ماند.
- [x] خطای ذخیرهٔ نام حساب، فرم و مقدارهای واردشده را نمی‌بندد یا پاک نمی‌کند.
- [x] پاسخ دیررس انتخاب ظاهر و بارگذاری تصویر به حساب یا جایگاه بعدی اعمال نمی‌شود.
- [x] کنترل تماس عمومی/پنهان، سقف و نوع تصویر و کنترل سمت سرور دست‌نخورده‌اند.

## آزمون‌ها

آزمون اختصاصی: `npm run check:resume-journey`؛ شامل ساخت واقعی پروژه، تماس نامعتبر، تنظیم ظاهر، خطا/تلاش دوبارهٔ نام حساب، انتخاب آدرس، یک درخواست انتشار، بازگشت به ویرایش مستقیم، یادآوری مرحله و عرض‌های ۱۴۴۰، ۳۹۰ و ۳۲۰ است. بخش‌های انتخابی ویستا و مکان آن‌ها در پیش‌نمایش نیز بررسی می‌شوند.

آزمون‌های موجود راهنمای کیفیت، احراز هویت اجتماعی، راهنمای فیلد، پنل و بازیابی انتشار با مسیر جدید سازگار شده‌اند؛ کنترل‌های امنیتی آن‌ها حذف نشده‌اند.

این آزمون‌ها حساب و دادهٔ آزمایشی دارند. بانک، پیامک و ارائه‌دهندگان OAuth شبیه‌سازی شده‌اند؛ نتیجهٔ محلی اثبات استقرار یا کارکرد سرویس زنده نیست. آزمون کاربردپذیری با کاربر واقعی هنوز انجام نشده است.
