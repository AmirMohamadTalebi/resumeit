# عملکرد داشبورد — ۱۲ اکتبر ۲۰۲۶

## امکانات متصل

- رزومه، مهارت، تجربه، تحصیلات، پروژه، گواهی، زبان، راه تماس، شبکه اجتماعی، تصویر، لینک و ترتیب/فعال‌بودن آن‌ها روی MySQL ذخیره می‌شوند؛ اطلاعات حساب‌ها جداست و در تب یا دستگاه دیگر بازیابی می‌شود.
- ذخیره با شمارهٔ نسخه انجام می‌شود؛ تغییرات هم‌زمان حساب در دو دستگاه یکدیگر را بی‌صدا بازنویسی نمی‌کنند. خطای ذخیره محتوا را در فرم نگه می‌دارد. پر شدن sessionStorage جلوی ذخیرهٔ سرور را نمی‌گیرد.
- نام صفحه در سرور اعتبارسنجی و رزرو می‌شود؛ نام تکراری، رزرو‌شده یا خارج از قواعد قبول نمی‌شود. تغییر نامِ ذخیره‌شده آدرس هر دو صفحه را تغییر می‌دهد.
- رزومه و لینک‌ها جداگانه منتشر و از انتشار برداشته می‌شوند. صفحهٔ عمومی آخرین نسخهٔ منتشرشده را نشان می‌دهد؛ ذخیرهٔ پیش‌نویس به معنی انتشار نیست. اطلاعات تماس غیرعمومی و لینک‌های غیرفعال نمایش داده نمی‌شوند.
- لینک، پروژه، ایمیل، تماس و شبکهٔ اجتماعی در نسخهٔ عمومی آدرس واقعی دارند. لینک‌های صفحهٔ لینک با شناسهٔ نسخهٔ منتشرشده به مقصد معتبر هدایت و شمارش می‌شوند؛ مقصد آزاد از query پذیرفته نمی‌شود.
- بازدید رزومه، بازدید لینک‌ها و کلیک روزانه روی MySQL ثبت می‌شوند؛ آمار خانه، لینک‌ها و صفحهٔ آمار از همین داده‌هاست. این اعداد تعداد درخواست‌اند، نه افراد یکتا، و ممکن است شامل ربات‌ها و بازدید تکراری باشند. IP و شناسهٔ بازدیدکننده ذخیره نمی‌شود.
- عنوان، توضیح، تصویر اشتراک‌گذاری و noindex در HTML عمومی ساخته می‌شود. noindex ابزار محرمانگی نیست؛ برای خصوصی‌شدن باید صفحه را از انتشار بردارید.
- قالب، فونت و رنگ رایگان در رابط و سرور اعتبارسنجی می‌شود؛ تغییر کد مرورگر دسترسی پولی ایجاد نمی‌کند.
- خروجی JSON از محتوای حساب، تنظیمات و وضعیت انتشار تهیه می‌شود؛ رمز یا کوکی نشست داخل فایل نیست. حذف حساب فقط با ورود معتبر، مبدأ صحیح و تأیید «حذف» ممکن است؛ داده‌ها، انتشار، آمار و نشست‌های وابسته حذف می‌شوند.

## آدرس و Runflare

آدرس اصلی رزومه `https://username.resumeit.ir` و لینک‌ها `https://username.resumeit.ir/links` است. مسیر جایگزین نیز آماده است: `https://resumeit.ir/u/username/` و `https://resumeit.ir/u/username/links`.

بررسی عمومی ۱۲ اکتبر: دامنهٔ اصلی پاسخ 200 دارد؛ نیم‌سرورها `ns1.runflare-dns.com` و `ns2.runflare-dns.com` هستند. نام تصادفی `codex-wildcard-check.resumeit.ir` پاسخ NXDOMAIN داشت. DNS، اتصال دامنه به پروژه و HTTPS زیردامنه هنوز انجام نشده است.

در تنظیمات DNS، رکورد CNAME با نام `*` را به همان مقصد هاستِ دامنهٔ اصلی هدایت کنید؛ اگر سرویس مقصد CNAME را متفاوت تعیین کرده، مقدار همان سرویس را به کار ببرید. دامنهٔ `*.resumeit.ir` باید به همان پروژه وصل و گواهی HTTPS مناسب فعال شود؛ رکورد DNS به‌تنهایی گواهی ایجاد نمی‌کند. رکورد دامنهٔ اصلی را حذف نکنید. نام‌هایی مانند `www`، `api` و `admin` برای حساب کاربران رزرو هستند.

متغیر هاست `PUBLIC_ORIGIN=https://resumeit.ir` است. کوکی ورود host-only باقی می‌ماند و API حساب روی زیردامنه‌های عمومی ارائه نمی‌شود. زیردامنه‌ها فقط صفحه و دارایی‌های عمومیِ مشخص‌شده را سرو می‌کنند.

راهنمای SSL سرویس: https://runflare.com/docs/how-to-work-with-ssl/

## محدودیت‌های روشن

پرداخت طبق درخواست فعلاً فعال نیست؛ انتخاب مورد پولی رسید یا مالکیت موفق ایجاد نمی‌کند. اتصال دامنهٔ مستقل و ارسال اعلان‌های خودکار هم فعال نیست؛ کنترل‌های نمایشی موفقیت حذف یا غیرفعال شده‌اند. گوگل و گیت‌هاب همیشه دیده می‌شوند و با تنظیم Client ID/Secret و callback دامنهٔ فعلی فعال می‌شوند؛ تنظیمات خصوصی فقط روی هاست نگهداری شوند.

مهاجرت افزایشی فقط دو جدول `dashboard_documents` و `dashboard_metrics` می‌سازد؛ دادهٔ قبلی حساب‌ها حذف یا بازنویسی نمی‌شود. تصاویر فعلاً در JSON محدود به درخواست ۸ مگابایتی ذخیره می‌شوند؛ برای کاربران پرتعداد به ذخیره‌ساز فایل نیاز خواهد بود.

## بررسی

`npm test` امنیت، ورود، OTP، OAuth و API داشبورد را بررسی می‌کند؛ `npm run check:ui` مسیرهای داشبورد، ذخیره بین تب‌ها، خطای شبکه، فرم‌ها و صفحهٔ عمومی در دسکتاپ/موبایل را بررسی می‌کند. `npm run check:database` ذخیره پس از بازکردن دوبارهٔ MySQL، نام تکراری و آمار را در دیتابیس موقت بررسی می‌کند و در CI با MySQL 8.4 اجرا می‌شود.

در این محیط MySQL محلی اتصال ندارد؛ تحویل پیامک، دستگاه واقعی، TLS wildcard و استقرار هاست از موفقیت تست‌های محلی نتیجه نمی‌شود.
