# اضافه‌کردن قالب رزومه

قالب از سه قسمت تشکیل می‌شود: تعریف در `dist/dashboard/js/data.js`، قرارداد ویرایشگر در `editor` همان تعریف، و نمایش در `dist/dashboard/js/preview.js`. قرارداد مشترک `resume-templates.js` هم در مرورگر و هم در سرور بارگذاری می‌شود؛ شرط انتشار و اعتبارسنجی صرفاً به مرورگر اعتماد نمی‌کنند.

کاربر از «ظاهر و قالب» قالب را انتخاب و پیش‌نمایش می‌کند. اطلاعات عمومی رزومه مشترک است؛ اطلاعات و تنظیمات اختصاصی در `resumeTemplates[templateId]` ذخیره می‌شود. عوض‌کردن قالب اطلاعات قالب قبلی را حذف نمی‌کند. بخش‌های پشتیبانی‌نشده از فرم و خروجی حذف می‌شوند، ولی دادهٔ آن‌ها نگه داشته می‌شود.

مثال قرارداد برای یک قالب دانشگاهی (نمونهٔ توسعه است؛ قالب جدیدی به سایت اضافه نشده):

```js
editor: {
  sections: ['contacts', 'education', 'projects', 'languages'],
  bodySections: ['education', 'projects'],
  requiredSections: ['education'],
  fields: [
    { key: 'thesis', label: 'عنوان پایان‌نامه', type: 'textarea', max: 300, required: true, public: true },
    { key: 'note', label: 'یادداشت شخصی', type: 'text', max: 500, public: false }
  ],
  settings: [
    { key: 'compact', label: 'چیدمان فشرده', type: 'checkbox', default: false },
    { key: 'density', label: 'فاصله‌ها', type: 'select', options: [['normal', 'معمولی'], ['wide', 'باز']], default: 'normal' }
  ]
}
```

انواع پشتیبانی‌شده `text`، `textarea`، `checkbox` و `select` هستند. کلیدها باید شناسهٔ ثابت و امن باشند و قبل از انتشار در کد تعریف شوند. فیلد ناشناخته، نوع اشتباه، گزینهٔ نامعتبر و متن بیش از حد مجاز روی سرور رد می‌شوند. دادهٔ اختصاصی فقط در صورت `public: true` توسط نمایش عمومی پیش‌فرض نشان داده می‌شود. تنظیمات خودکار به اطلاعات عمومی تبدیل نمی‌شوند.

قالب‌های موجود بدون `editor` همان بخش‌ها و شرط‌های معمول قبلی را دارند. `sections` بخش‌های قابل استفاده را تعیین می‌کند، `requiredSections` بخش‌هایی را که باید پر و نمایان باشند، و `bodySections` گروهی که حداقل یکی از آن‌ها باید پر و نمایان باشد. آرایهٔ خالی شرط گروه را حذف می‌کند. نام و عنوان رزومه و نام معتبر صفحه همچنان الزامی‌اند؛ راه تماس فقط برای قالبی الزامی است که بخش تماس را پشتیبانی می‌کند. شروط تکمیل حساب و شمارهٔ تأییدشده مستقل از قالب باقی می‌مانند.

برای طراحی کاملاً متفاوت می‌توان تابع مورد اعتماد `RI.RESUME_RENDERERS[id]` را در کد نمایش ثبت کرد. تابع دادهٔ رزومه و `{ theme, spec, values, publicBase }` را می‌گیرد و HTML تولید می‌کند. همان تابع در پیش‌نمایش و صفحهٔ عمومی اجرا می‌شود. دادهٔ کاربر باید با `RI.esc` خروجی شود، لینک‌ها با قواعد موجود اعتبارسنجی شوند و تماس‌های خصوصی حذف شوند. HTML یا JavaScript ارسالی کاربر هرگز به عنوان قالب اجرا نمی‌شود.

برای هر قالب واقعی، نمایش اختصاصی تنظیمات آن، تصویر نمونه و آزمون موبایل/دسکتاپ باید همراه قالب اضافه شود. این آماده‌سازی قالب‌های ارسالی آینده را حدس نمی‌زند و طراحی جدیدی به جای فایل‌های شما نمی‌سازد.

آزمون قرارداد: `node tests/resume-templates-check.cjs`؛ شامل شرط‌های متفاوت، حفظ اطلاعات هنگام تغییر قالب، اعتبارسنجی نوع/طول و نمایش امن اطلاعات عمومی است.
