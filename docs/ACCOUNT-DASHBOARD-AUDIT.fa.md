# اصلاحات ممیزی۱۱تا۱۵

۲۰ اکتبر۲۰۲۶؛ اصلاحات محلی روی main مبتنی بر0.24.5-beta. هنوز commit/push یا انتشار این نوبت انجام نشده است.

## نتیجه

- [x] ۱۱: انقضای تأیید بن‌بست ندارد؛ شماره حفظ، رمزهای پنهان/نمایان پاک و شمارنده فارسی درست شد.
- [x] ۱۲: مقصد معتبر داخلی در ورود رمز/OTP/OAuth حفظ می‌شود؛ هر شروع OAuth مقصد تازه می‌گیرد؛ ادامه حساب فعلی اختیاری و label رمز مستقل است.
- [x] ۱۳: متن ارسال کد مشروط؛ کمک هنگام ازدست‌دادن شماره به ورود متصل قبلی/تماس موجود، بدون مسیر دورزدن هویت.
- [x] ۱۴: صحنه تزئینی inert؛ منو به آغازگر واقعی برمی‌گردد؛ پیشرفت محتوا از آمادگی انتشار جدا؛ جایگاه فقط‌لینک فقط اقدامات مرتبط دارد؛ CTA زبانه درست را باز می‌کند.
- [x] ۱۵: حذف فهرست تکراری و خودلینک استودیو؛ نام اقدام شامل موضوع و نوع صفحه؛ نمایش کاملِ قفل‌شده جدا از آمادهٔ مجاز؛ اعتبار قالب نام به‌جای ادعای آزادبودن.

## شورا

هر بخش پس از اجرا جداگانه به Rams، Torvalds و Ada داده شد؛ Rams وزن۱.۵ داشت، بقیه۱. هر پنج جلسه با3.5/3.5 به fixed رسیدند. Root رئیس مستقل بود. همه نقش‌ها از یک ارائه‌دهنده‌اند؛ این توافق چند ارائه‌دهنده مستقل نیست.

بازبینی واقعاً ایراد تازه پیدا کرد: رمز نمایان، مقصد قدیمی OAuth، متادیتای زبانه CTA، شماره‌گذاری راهنما و درصدهای گرد‌شده ناسازگار پیش از تأیید نهایی اصلاح شدند.

## اعتبارسنجی

- npm run check:account-audit: چهار آزمون جدید انقضا/شمارنده/حریم خصوصی، مقصد ورود، خانه و استودیو؛ در CI افزوده شد.
- npm test همراه posttest: مجموعه کامل بک‌اند موفق.
- auth-ui-check، auth-mobile-check، oauth-check، dashboard-check، multipage-ui-check و compact-pages-ui-check موفق.
- تست قدیمی dashboard-check با مسیر فعلی ویرایش مهارت هماهنگ شد؛ کنترل نام مهارت در لیست ویرایشگر و نگهداری داده همچنان آزموده می‌شود.
- تصاویر قبل/بعد و صورت‌جلسات محلی در artifacts/council-audit-2026-10-20/ قرار دارند؛ فایل POST-IMPLEMENTATION-COUNCIL.fa.md جمع‌بندی جلسات تأیید است.

## حدود

حساب‌ها و سرویس‌های آزمون جدا و ساختگی‌اند؛ انتشار واقعی، SMS/OAuth واقعی، صفحه‌خوان انسانی و دستگاه فیزیکی بررسی نشده‌اند. آماده‌بودن رابط تضمین موفقیت آینده انتشار نیست؛ اعتبارسنجی سرور حفظ شده است. همه۳۰ آزمون مجموعه UI یکجا اجرا نشدند؛ آزمون‌های مرتبط بالا اجرا شدند.
