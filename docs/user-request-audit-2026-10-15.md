# ممیزی درخواست پنل کاربر

تاریخ ممیزی اولیه: ۲۳ مهر ۱۴۰۵ / 2026-10-15. سپس با درخواست مالک، فقط موارد ناقص اجرا شدند. تیک‌های جدید زیر به معنی اصلاح و تست محلی‌اند؛ انتشار و تحویل واقعی پیام هنوز تأیید نشده است. دامنه طبق پاسخ تازهٔ مالک همچنان موکول است.

## نتیجهٔ اصلی

- در ممیزی اولیه، نسخهٔ عمومی سایت با درخواست به `https://resumeit.ir/api/version` برابر `0.21.9-beta` بود. این بخش ثبت همان مشاهده است، نه ادعای بررسی دوبارهٔ سایت زنده در نوبت فعلی.
- نسخهٔ تازه `0.22.0-beta` است. مالک در ادامه مجوز انتشار در گیت‌هاب را داد؛ تغییرات این سند برای همان انتشار آماده شده‌اند. نتیجهٔ push جدا گزارش می‌شود و وجود قابلیت در مخزن، اثبات استقرار روی سایت نیست.
- ابزار مرورگر نتوانست نشست واردشده را باز کند: `failed to write kernel assets`. درخواست بدون نشست برای فایل داشبورد زنده نیز پاسخ `303 /login/` می‌گیرد. بنابراین پنل خصوصی زنده و دیتابیس واقعی تأیید نشده‌اند.
- متن قدیمی «پرداخت آنلاین در حال حاضر غیرفعال است» در پاسخ تازهٔ صفحهٔ عمومی `https://resumeit.ir/contact/` یافت شد.
- دامنهٔ شخصی عمداً برای نوبت بعد عقب افتاده؛ این مورد فراموش‌شده یا انجام‌شده محسوب نمی‌شود. پیش از اجرای آن باید جزئیاتش از مالک گرفته شود.

## بازبینی با درخواست‌های جدید

این بخش، درخواست‌های بعد از ممیزی اولیه را هم پوشش می‌دهد. آزمون‌ها محلی‌اند؛ جدول‌های واقعی MySQL، DNS، تحویل سرویس و استقرار زنده در این نوبت آزموده نشده‌اند.

### چندصفحه‌ای و آدرس‌ها

- [x] حساب دارای اشتراک فعال، دو جایگاه زیردامنه برای مجموع دو رزومه و دو لینک، و یک جایگاه مخصوص لینک روی دامنهٔ اصلی دارد؛ بیش از سه لینک یا دو رزومه از API قابل ساخت نیست.
- [x] مدل نهایی مالک اجرا شده: `name1.resumeit.ir` رزومه، `name1.resumeit.ir/link` لینک؛ جایگاه دوم هم همین مدل را دارد. آدرس سوم `resumeit.ir/name3` فقط لینک است.
- [x] مسیر لینک قابل تغییر و غیرخالی است؛ رزومه می‌تواند مسیر اختیاری مانند `/cv` داشته باشد. یکسان‌بودن مسیرها و مسیر سیستمی رد می‌شود.
- [x] ریشهٔ رزومه و مسیر قدیمی `/links` به‌صورت سازگار باقی می‌مانند؛ مسیرهای سفارشی قبلی بعد از تغییر دوباره به‌صورت نامحدود alias نمی‌شوند.
- [x] راهنمای نام در فرم: ۳ تا ۲۴ نویسه، حروف کوچک انگلیسی، عدد و خط تیره؛ بدون فارسی، فاصله، خط تیرهٔ ابتدا/انتها یا دو خط تیرهٔ متوالی.
- [x] راهنمای مسیر: ۱ تا ۲۴ نویسه؛ مسیر لینک خالی نیست. نام‌های سیستمی و مسیرهای داخلی مانند `out` و `share-image` ممنوع‌اند.
- [x] نام گرفته‌شده در ثبت اتمیک سرور رد می‌شود؛ یک کاربر هم نمی‌تواند دو جایگاه زیردامنه را با یک نام بگیرد. فضای نام دامنهٔ اصلی و زیردامنه مستقل است.
- [x] انتخاب جایگاه در استودیو، رزومه، لینک، قالب و انتشار وجود دارد؛ نام‌ها، پیش‌نویس‌ها، نسخه‌ها، مسیرها و تصاویر جایگاه‌ها مستقل‌اند.
- [x] تغییر جایگاه، ذخیره/انصراف از تغییرات قبلی را تعیین‌تکلیف می‌کند؛ انتخاب بعد از رفرش حفظ می‌شود و تغییر حساب، جایگاه قبلی شخص دیگر را به حساب جدید تحمیل نمی‌کند.
- [x] آمار مشاهده/کلیک جایگاه‌ها جداست و تصویر خصوصی جایگاه دوم از حساب دیگر خوانده نمی‌شود.
- [x] QR و متادیتا از مسیر سفارشی درست استفاده می‌کنند؛ جایگاه سوم منوی رزومه یا امکان انتشار رزومه ندارد.
- [x] پایان اشتراک، ویرایش/انتشار و نمایش عمومی جایگاه‌های اضافه را متوقف می‌کند؛ محتوا و نام رزروشده حذف نمی‌شوند و با تمدید دوباره نمایش ممکن است. جایگاه اول با دسترسی رایگان باقی می‌ماند.
- [x] نام‌های موجود در `dashboard_documents` با مهاجرت افزایشی وارد فهرست رزرو می‌شوند؛ جدول اصلی حذف یا جایگزین نشده است.
- [ ] **تأییدنشده:** مهاجرت، قفل‌های هم‌زمان MySQL و DNS/HTTPS زیردامنه‌های دوم روی هاست واقعی آزموده نشده‌اند. تست محلی از SQL تولید و SQLite موقت استفاده می‌کند.

### اصلاحات رابط و انتشار

- [x] نوار بالا در دسکتاپ و موبایل پس‌زمینهٔ شیشه‌ای مات دارد و با محتوای پشت مخلوط نمی‌شود.
- [x] انتشار از نوار ثابت همهٔ فرم‌ها بدون ترک فرم انجام می‌شود؛ برای جایگاه سوم فقط لینک پیشنهاد می‌شود.
- [x] دکمهٔ ابتدایی «رفتن به انتشار» حذف و شروع آمادگی انتشار با خلاصهٔ واقعی و شمارش کمبودها جایگزین شد.
- [x] باز و بسته‌شدن جزئیات نرم، قابل قطع و تکرار است؛ کاهش حرکت رعایت می‌شود.
- [x] کنترل همگام‌سازی معرفی، لینک مستقیم ویرایش معرفی و خلاصهٔ قالب فعلی مرتب شدند.
- [x] سرچ و selectهای پنل یکدست شدند؛ مرورگر پشتیبان `base-select` پنجرهٔ انتخاب سفارشی دارد و بقیه از کنترل بومی استفاده می‌کنند.
- [x] پنجرهٔ میانی جزئیات قالب حذف شد؛ کلیک کارت مستقیم پیش‌نمایش و دکمهٔ جداگانهٔ «استفاده» انتخاب را انجام می‌دهد.
- [x] رنگ‌ها نمونهٔ زنده دارند و چیدمان موبایل دو ستونی است؛ تغییر رنگ نمونه را تازه می‌کند.
- [x] مالک اجازهٔ انتشار تغییرات تا این مرحله را داد؛ نتیجهٔ انتقال به مخزن و استقرار مستقل گزارش می‌شود. این تیک جای قضاوت نهایی زیبایی توسط مالک نیست.

- [ ] **مرز عمدی:** تغییر شماره/تأیید هویت، رمز یا نقش مدیر از فرم عمومی ویرایش اطلاعات مجاز نشده است؛ بنابراین «ویرایش همهٔ اطلاعات و اعتبارنامه‌ها» به‌طور نامحدود پیاده نشده و نباید ادعای آن شود.

- [x] فهرست صفحه‌ها، جزئیات کاربر، جمع بازدید و گزارش کلی مدیریت جایگاه‌های اضافه را هم می‌خوانند؛ ردیف سوم لینکِ دامنهٔ اصلی آدرس درست دارد. تعلیق/توقف انتشار در خروجی تمام جایگاه‌ها اعمال می‌شود.
- [ ] **بازبینی جامع باقی است:** ادعای «همهٔ قابلیت‌های مدیر» یا ممیزی امنیت تمام مسیرهای قدیمی از این تست‌های پنل کاربر نتیجه نمی‌شود؛ بارگذاری فایل، وب‌هوک‌ها و تمام فرم‌های سایت به ممیزی جداگانهٔ سراسری نیاز دارند. تست‌های موجود بخشی از اعتبارسنجی تصویر، URL، دسترسی و تزریق را پوشش می‌دهند، نه همهٔ حملات ممکن را.

## مواردی که پیش از اعلام «کامل شد» باقی مانده‌اند

1. مالک انتشار را تأیید کرده است. انتشار مخزن با حفظ مبنای آخرین تغییرات مالک انجام می‌شود؛ وضعیت استقرار واقعی باید از پاسخ نسخهٔ سایت یا میزبان جدا ثابت شود.
2. تنظیم متغیرهای سه کانال در رانفلر و بررسی تحویل واقعی در مقصد متعلق به مالک، نه اعلام موفقیت صرفاً از روی کد.
3. بررسی پنل واردشده و MySQL واقعی؛ تنظیم MySQL در محیط محلی موجود نیست و ابزار مرورگر نشست زنده خطا دارد.
4. بررسی کارت پیام‌رسان و زمان تأیید پرداخت روی استقرار واقعی؛ بدون ساخت پرداخت تازه مگر با مجوز جداگانه. نمایه‌شدن گوگل و افزایش فروش نیاز به زمان/داده دارند و فوری قابل تیک‌زدن نیستند.
5. دامنهٔ شخصی طبق پاسخ جدید مالک همچنان برای نوبت بعد نگه داشته شده است.
6. تغییر اعتبارنامه و نقش از فرم ویرایش عمومی عمداً مجاز نیست؛ ارزیابی جامع امنیت و استقرار واقعی جای تست محلی را نمی‌گیرد.

## شواهد و حدود تست

در بازبینی تازه، `npm test` شامل `multipage-check.cjs` و `notification-policy-check.cjs` گذشت. `npm run check:multipage` نیز تعویض جایگاه، تعیین‌تکلیف ذخیره، ریست جایگاه با تغییر حساب، مسیر سفارشی، آدرس‌های زنده‌شدهٔ محلی و عکس‌های ۱۴۴۰/۳۹۰/۳۲۰ را تأیید کرد. `workspace-revision-ui-check.cjs` برای صفحات قبلی هم گذشت. شواهد جدید در `artifacts/multipage/` و `artifacts/communication-polish/` قرار دارند.

این تیک‌ها نتیجهٔ کد و تست‌های همین نسخه‌اند، نه تست استقرار. تست `admin-completion-check.cjs` منطق SQL تولید برای حذف/ویرایش مشخصات، گزارش چندصفحه‌ای و کنترل درگاه و ادامهٔ تأیید پرداخت قبلی را بررسی می‌کند. تست مرورگر `admin-completion-ui-check.cjs` فرم‌ها و کلیدهای مدیر را در دسکتاپ و موبایل بررسی کرد؛ عکس‌ها در `artifacts/admin-completion/` محلی‌اند. ممیزی تمام سطح حملهٔ سایت یا تحویل سرویس خارجی از این تست‌ها نتیجه نمی‌شود.

مجموعهٔ `npm test` همراه تست‌های جدید `notification-delivery-check.cjs`، `revision-completion-check.cjs` و `payment-status-poll-check.cjs` گذشت. تست رابط `workspace-revision-ui-check.cjs` نیز چهار عرض و مسیر امضای سفارشی، کد ایمیل شبیه‌سازی‌شده و انتخاب آدرس کنار فرم را بررسی می‌کند. تست‌های کانال، سرویس شبیه‌سازی‌شده و SQLite موقت دارند و جای MySQL، مقصد پیام یا درگاه واقعی را نمی‌گیرند.
