## تغییرهای قابل مشاهده

- [x] یک مسیر اصلی برای بخش‌های هر قالب: معرفی/هیرو، بخش‌های محتوایی به ترتیب واقعی پیش‌نمایش، سپس تماس و تنظیمات مشترک.
- [x] ترتیب ذخیره‌شدهٔ بخش‌ها در تب‌ها و پیش‌نمایش از یک resolver مشترک استفاده می‌کند؛ پروژه‌ها هم در جای واقعی خود هستند.
- [x] تنظیمات هر بخش کنار همان تب قرار دارد. انتخابگرهای تکراریِ صفحه/بخش/نوع در ویرایش مستقیم حذف شده‌اند؛ مسیر راهنمای مرحله‌به‌مرحله همچنان کار می‌کند.
- [x] هاور تب آرام، وضعیت انتخاب مشخص و فوکوس صفحه‌کلید دیده می‌شود؛ قاعدهٔ سراسری هاور تیره که ظاهر تب‌ها را خراب می‌کرد حذف شد.
- [x] راهنمای کوتاه با هاور یا فوکوس؛ Escape برای بستن؛ کلیک/لمس برای توضیح کامل.
- [x] گزینهٔ نمایش قالب به checkbox کوچک و عنوان روشن تبدیل شد؛ نمایش ویستا دیگر کنترل بزرگ و مبهم نیست.
- [x] تصویر: پیش‌نمایش، انتخاب فارسی، حذف، توضیح تصویر در کنار آن؛ آدرس فنی در قسمت اختیاری. خطای فایل کنار کنترل و قابل تشخیص برای فناوری کمکی است.
- [x] درصد: ورودی عددی ۰ تا ۱۰۰؛ ذخیره در قالب قبلی درصد، بدون تغییر مدل داده.
- [x] لینک: انتخاب صفحهٔ داخلی یا ورود آدرس؛ تغییر حالت مقدار قبلی را پاک نمی‌کند.
- [x] اطلاعات مشترک معرفی یک منبع دارند؛ فیلد دومِ قابل ویرایش برای نام/عکس ایجاد نشد.
- [x] رنگ‌های جزئی، عنوان‌های فنی و گزینه‌های قدیمی در «گزینه‌های بیشتر» حفظ شده‌اند.
- [x] بخش تماس قدیمی ساتیار که خروجی ندارد از ترتیب بصری حذف شد؛ مقادیر قبلی با توضیح صریح در سازگاری قابل دسترسی‌اند. تماس اصلی همان اطلاعات تماس واقعی است.
- [x] پاسخ دیررس انتخاب تصویر نمی‌تواند انتخاب تازه، آدرس دستی یا حذف تصویر را بازنویسی کند؛ کنترل مالک، فضای کاری و محتوای فعال هم حفظ شد.
