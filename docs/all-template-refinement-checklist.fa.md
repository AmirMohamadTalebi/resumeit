## اصلاحات مشترک

- [x] نمونه‌های مستقل همان پوشش واکنش‌گرای خروجی عمومی را دارند؛ حالت دو ستونی در موبایل به تک‌ستونی تبدیل می‌شود.
- [x] سرریز عرض در یخچال، ترمینال و سه قالب چیدمان تصویری برطرف شد؛ عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ بررسی شدند.
- [x] اندازهٔ نشان رزومیت در فوتر محدود شد؛ در حالت تیره خوانا می‌ماند و تنظیم مخفی/سفارشی حفظ شده است.
- [x] پنجرهٔ پروژه در مرکز، با حاشیهٔ امن و محدودیت ارتفاع قرار می‌گیرد؛ Escape و بستن حفظ شده‌اند.
- [x] کارت پروژهٔ بدون عکس، سطح خالی بزرگ ندارد؛ عکس واقعی حفظ می‌شود. کارت خلاصه و پنجره متن کامل و مقصد را نشان می‌دهد.
- [x] پنجرهٔ پروژه در قالب‌های تیره رنگ همان قالب را می‌گیرد.
- [x] نام و عنوان بلند، مهارت بلند، نشانی تماس و نام کاربری شبکهٔ اجتماعی صفحه را از کادر خارج نمی‌کنند.
- [x] شش شبکهٔ اجتماعی هم‌زمان در صفحهٔ لینک در موبایل جا می‌گیرند و در صورت نیاز به سطر بعد می‌روند.
- [x] رنگ متن دکمهٔ لینک از توکن خود دکمه گرفته می‌شود، نه رنگ عمومی صفحه؛ مشکل کاکائو و غروب رفع شد.
- [x] رنگ نوشتهٔ روی رنگ سفارشی بر اساس کنتراست سیاه/سفید انتخاب می‌شود؛ خوانایی نشانگر فوکوس هم اصلاح شد.
- [x] نام صاحب رزومه H1 است؛ بخش‌های اصلی قالب‌های استاندارد H2 دارند و عنوان خالی باقی نمی‌ماند.
- [x] تصویر پروفایل قالب‌های استاندارد alt معنادار دارد؛ اطلاعات تماس خصوصی در خروجی نمی‌آید.
- [x] پیام خالی خروجی عمومی دیگر دستور کار با پنل ویرایش نیست.
- [x] برچسب اطلاعات آزمایشی در جریان صفحه قرار دارد و روی محتوا یا کنترل‌ها نمی‌افتد.
- [x] دکمهٔ لینک در نمونهٔ رزومه به نمونهٔ معتبر می‌رود؛ نمونهٔ لینک از مسیر رهگیریِ مخصوص حساب واقعی استفاده نمی‌کند. مقصدهای محلی با پاسخ ۲۰۰ بررسی شدند.
- [x] نمونه‌های ثابت و عکس‌های فهرست قالب‌ها بازسازی شدند؛ توضیح فهرست ویستا/ساتیار دیگر مقاله و صفحهٔ فرعی وعده نمی‌دهد.
- [x] کاهش حرکت در همهٔ ۱۶ قالب، با نام‌ها و محتوای بلند و بدون تصویر آپلودی بررسی شد.

## شواهد و آزمون‌ها

- `npm test`: پاس؛ پایگاه دادهٔ محلی و سرویس‌های بیرونی شبیه‌سازی‌شده، نه تأیید رفتار میزبان یا بانک.
- `npm run check:advisor`: پاس؛ گردش پنل، پیش‌نمایش، راهنما و انتشار محلی نیز بررسی شدند.
- `npm run check:templates`: قرارداد داده، ساتیار، ۴۸ حالت قالب/عرض، ۱۶ حالت فشار محتوا و مقصدهای نمونه.
- آزمون‌های جداگانهٔ ویستا: پاس؛ کنترل منو، iframe پیش‌نمایش، کنتراست و حرکت حفظ شده‌اند.
- `git diff --check`: پاس.

اعداد ۳۹۰ پیکسل برای نمونه‌های استاندارد: یخچال/ترمینال حدود ۲۲۶۷ پیکسل، قالب‌های تک‌ستونی حدود ۲۲۳۱، مدل‌های تصویری حدود ۲۶۴۴ و صفحات لینک حدود ۹۴۶. با محتوای واقعی بیشتر یا بازکردن جزئیات، ارتفاع بیشتر می‌شود.

فایل‌های شواهد محلی در `artifacts/all-template-refinement/` هستند: `baseline.json`، `results.json`، `edge-results.json`، `satiar-details.json`، لاگ آزمون‌ها و عکس هر قالب. تصویر جمعی: `all-templates-mobile.png`.

## محدودیت‌ها

روی گوشی فیزیکی، مرورگر شخصی کاربر و سایت زنده تست نشده است. همهٔ ترکیب‌های رنگ/فونت سفارشی و تطابق کامل WCAG تأیید نشده‌اند. فایل‌های اصلی قالب و کلیدهای داده برای حفظ سازگاری کاربر نگه داشته شده‌اند؛ حذف کامل دادهٔ قدیمی یا مهاجرت قرارداد ذخیره‌سازی در این مرحله انجام نشده است. انتشار روی گیت‌هاب و سه پیشنهاد اختیاری گزارش ویستا خارج از این مرحله‌اند.
