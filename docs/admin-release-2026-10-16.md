# گزارش محلی نسخهٔ ۰.۲۳.۰

این گزارش نتیجهٔ محیط محلی و دادهٔ آزمایشی است، نه تأیید استقرار رانفلر یا عملکرد ارائه‌دهندگان زنده.

## شاهدها
- `npm test`: پاس؛ امنیت، احراز هویت، پرداخت، سهمیه، نقش، اعلان، فیلتر SQL و نگهداری سوابق.
- `npm run check:ui`: هر ۲۹ مجموعه پاس؛ چهار نقش، ویرایش حساب و محصول، تب‌بندی، فیلتر و صفحه‌بندی، واکنش‌گرایی و عملیات گروهی.
- `npm run check:ui-layout`: ۲۸۶ حالت، شش عرض ۳۲۰/۳۹۰/۷۶۸/۱۰۲۴/۱۴۴۰/۱۹۲۰، ۹۳ انتخابگر و ۲۴ منو؛ صفر بیرون‌زدگی، هم‌پوشانی، خطای مرورگر یا پاسخ ناموفق محلی.
- `npm run check:contrast`: ۳۵ مسیر و ۷۷ حالت hover/focus، رنگ عادی و تقریب گرم، forced-colors و reduced-motion پاس. تست فیزیکی Night Light انجام نشده است.
- `tests/admin-workflow-ui-check.cjs`: در عرض‌های ۱۴۴۰/۳۹۰/۳۲۰ تعلیق/رفع تعلیق گروهی با SQL واقعیِ fixture، توقف/ادامه فروش، ویرایش قیمت/مشخصات، تفکیک نرخ It، سهمیه و رسید و بایگانی/بازگردانی اجرا شد.
- `tests/admin-filters-check.cjs`: SQL تولید روی SQLite؛ جست‌وجوی پارامتری فارسی و ارقام، نقش‌ها، بازه، مبلغ، آمار خرید و شمارش صفحات مطابق سهمیهٔ عددی و نامحدود پاس.
- `tests/retention-check.cjs`: اصل اسناد مالی باقی ماند؛ تیکت باز، اعلان نخوانده و پرداخت در انتظار حفظ شد؛ تکرار عملیات شارژ یا حذف دوباره ایجاد نکرد.
- `tests/image-alt-check.cjs`: ۱۰۰ فایل HTML و ۶۸ صفحهٔ قالب، ۲۱۶۴ تصویر بدون alt مفقود. معنای همهٔ توصیف‌ها به‌صورت دستی بررسی نشده است.
- `tests/enamad-footer-check.cjs`: تصویر موفق/خراب/cache، بدون JavaScript، متن استعلام دامنه و alt پاس؛ سرویس واقعی اینماد بررسی نشد.

## تغییر داده و نکتهٔ انتشار
مهاجرت هنگام شروع سرور اجرا می‌شود: جدول `admin_archives` و ستون nullable `wallet_transactions.product_ref` همراه شاخص اضافه می‌شوند؛ دادهٔ قبلی بازنویسی یا حذف نمی‌شود. اعتبار موجود و نرخ فاکتور قبلی ثابت می‌مانند. پیش از استقرار، نسخهٔ پشتیبان معمول دیتابیس لازم است؛ این مهاجرت روی MySQL واقعی در این نوبت اجرا نشده است.

گزارش مالی و لاگ مدیریت بایگانی می‌شوند و قابل بازگردانی‌اند. پاک‌سازی دائمی فقط برای موارد مجاز قدیمی با تأیید مالک و حداکثر ۲۰۰ مورد در هر نوبت است. خریدهای قدیمی فاقد شناسهٔ محصول در مجموع کل حفظ می‌شوند و فروش هر محصول به آن‌ها حدسی نسبت داده نمی‌شود.

## باز مانده
سقف سه ارتفاع هنوز در تمام صفحه‌ها برقرار نیست؛ اندازه‌های واقعی در ST-11 چک‌لیست ثبت شد. دامنهٔ شخصی طبق خواستهٔ کاربر به نوبت بعد موکول است. تحویل زندهٔ SMTP/SMS/Push، علت قطعی تأخیر بانک، وضعیت واقعی تصویر اینماد و شاهد پیام قبلی تلگرام تأیید نشده‌اند. هیچ پرداخت یا پیام زنده‌ای برای تست ارسال نشد. بعد از push بنا بر درخواست کاربر بررسی زنده انجام نمی‌شود.
