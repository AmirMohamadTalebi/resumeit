# قالب‌های ویستا و ساتیار

دو نسخهٔ آفلاین ارسالی (هرکدام ۱۱۸٬۰۰۰ تومان / ۵۹ It؛ خرید یک‌باره یا اشتراک فعال) به گالری ویژهٔ رزومه اضافه شده‌اند. ویستا ۳۰ صفحه و ساتیار ۲۴ صفحهٔ محتوایی دارند؛ صفحات تکراری دسته‌بندی، برچسب، نویسنده و صفحه‌بندی آرشیو به‌عنوان قالب جدا وارد نشده‌اند. طراحی، CSS، فونت‌ها، تصاویر، صفحات مقاله و نمونه‌کار از فایل‌های ارسالی استفاده می‌کنند.

## مسیر استفاده

۱. داشبورد ← «ظاهر و قالب» ← انتخاب ویستا یا ساتیار.
۲. «رزومه» ← «ویژهٔ قالب» ← انتخاب صفحه و بخش؛ سپس محتوای ثابت یا مجموعهٔ تکرارشونده و مورد موردنظر. متن، تصویر، لینک و تنظیمات نمایش فیلتر جدا دارند؛ هر صفحه حداکثر ۸ فیلد دارد.
۳. تغییر متن، عکس، تصویر زمینه، مقصد دکمه، آیکن، رنگ، فونت یا حالت روشن/تیره.
۴. برای آیتم‌های تکرارشونده، افزودن مورد مشابه، حذف و جابه‌جایی. بخش‌ها را می‌توان پنهان یا جابه‌جا کرد. درصد مهارت به عرض واقعی نوار مهارت وصل است.
۵. بررسی محتوای نمونه، تأیید بررسی، ذخیره و سپس انتشار. ویرایش محتوای قالب تأیید بررسی را دوباره غیرفعال می‌کند.

نام، عنوان، معرفی، عکس اصلی و راه‌های تماس به اطلاعات حساب رزومه وصل‌اند؛ فیلدهای اختصاصی هر قالب در `resumeTemplates[templateId]` می‌مانند. تغییر قالب یا پنهان‌کردن بخش‌ها دادهٔ قبلی را حذف نمی‌کند. دادهٔ مشترک قالب‌های قدیمی نیز حفظ می‌شود؛ سایر بخش‌های طراحی‌های ارسالی از ویرایشگر اختصاصی آن قالب تنظیم می‌شوند.

## ذخیره‌سازی و انتشار

جدول فعلی `dashboard_documents` استفاده می‌شود و مهاجرت مخرب یا جدول جدا برای هر قالب لازم نیست. فقط تغییرات نسبت به تعریف قالب در JSON پیش‌نویس ذخیره می‌شوند؛ HTML و CSS طراحی، کد مورد اعتماد پروژه‌اند و وارد دادهٔ حساب نمی‌شوند.

- `fields`: متن‌ها، تصاویر، لینک‌ها، آیکن‌ها و درصدهای اختصاصی.
- `settings`: رنگ‌ها، تصویر زمینه، نمایش بخش‌ها، ترتیب بخش‌ها، فونت، حالت و تأیید بررسی.
- `collections`: آیتم‌های تکرارشونده با شناسه و فیلدهای مستقل؛ حداکثر ۳۰ مورد برای هر نقطهٔ تکرار و ۳۰۰ مورد سفارشی برای هر قالب.

صفحات داخلی از مسیر `/?page=...` روی زیردامنهٔ خود کاربر باز می‌شوند. مقصد داخلی را می‌توان از انتخابگر صفحه انتخاب کرد یا لینک خارجی معتبر وارد کرد. آدرس صفحهٔ ناشناخته ۴۰۴ می‌دهد. نسخهٔ عمومی همچنان از snapshot منتشرشده ساخته می‌شود؛ ذخیرهٔ پیش‌نویس نسخهٔ عمومی را تغییر نمی‌دهد.

## ایمنی و رفتار واقعی

اسکریپت‌های WordPress، Elementor، رهگیری، فرم‌های ورود، ارسال نظر و درخواست‌های AJAX سایت مبدأ اجرا نمی‌شوند. منو، جابه‌جایی صفحه، حالت روشن/تیره و بازگشت به بالا با اسکریپت داخلی ResumeIt کار می‌کنند. فایل‌های موردنیاز محلی‌اند؛ سه آواتار Gravatar که در دانلود نبودند با تصویر عمومی جایگزین شده‌اند و در گزارش واردسازی ثبت شده‌اند.

راه تماس خصوصی در خروجی عمومی قرار نمی‌گیرد. فرم تماس در صورت وجود ایمیل عمومی، پیام را در برنامهٔ ایمیل دستگاه باز می‌کند؛ صندوق پیام یا ارسال ایمیل از سرور ساخته نشده است و این محدودیت در خود فرم نوشته شده. تعرفه‌های قالب نمایش/لینک تماس‌اند و پرداختی انجام نمی‌شود.

متن و ویژگی‌های HTML escape می‌شوند؛ URL، رنگ، تصویر، آیکن، درصد، ترتیب و ساختار لیست‌ها روی سرور اعتبارسنجی می‌شوند. PNG/JPEG/WebP بارگذاری‌شده باید امضای فایل معتبر داشته باشد. HTML، CSS یا JavaScript دلخواه کاربر اجرا نمی‌شود. پیش‌نمایش در iframe بدون اجازهٔ اجرای اسکریپت جداست تا CSS طراحی داشبورد را تغییر ندهد. تعریف‌های بزرگ قالب با gzip منتقل می‌شوند.

## فایل‌ها و بررسی

- `scripts/import-resume-templates.py`: واردسازی قابل تکرار از پوشهٔ منبع؛ فقط در توسعه اجرا می‌شود و برای اجرای سایت Python لازم نیست.
- `dist/dashboard/js/template-vista.js` و `template-satiar.js`: تعریف‌های تولیدشدهٔ طراحی و قرارداد محتوا.
- `imported-templates.js`: قرارداد و نمایش مشترک سرور/پیش‌نمایش.
- `template-editor.js`: ویرایشگر اختصاصی داشبورد.
- `dist/templates/`: CSS، فونت، تصویر و رفتار عمومی هر قالب.
- `docs/template-*-import.json`: تعداد صفحه/فیلد/آیتم و فایل‌های مفقود منبع.
- `tests/imported-templates-check.cjs`: تمام صفحه‌ها، دادهٔ معتبر، تزریق، تماس خصوصی و حفظ داده هنگام تغییر قالب.
- `tests/imported-templates-ui-check.cjs`: بارگذاری تمام صفحه‌ها، موبایل/دسکتاپ، دارایی‌ها، پیش‌نمایش جدا، ویرایش و ذخیره/بارگذاری مجدد.

متن‌ها، نام‌ها، عکس‌ها، آمار و نظرهای اولیه نمونهٔ طراحی‌اند؛ کاربر باید آن‌ها را پیش از انتشار بررسی و اصلاح کند. تغییر تعداد نامحدود صفحه یا اجرای افزونه‌های WordPress بخشی از این قرارداد نیست؛ هر صفحهٔ موجود و آیتم‌های تکرارشوندهٔ آن قابل شخصی‌سازی هستند.
