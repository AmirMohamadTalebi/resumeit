## ترتیب ریلیز (برخوردهای فایل)

1. **پایه:** C2-b سمت سرور (`notifyOnce`)، R1-bc، R3-b، R3-d، R2-c، C1-c.
2. **مالی:** R2-a فاز ۱ ← R2-d ← R2-a فاز ۲ ← نوار UI C2-b. C2-a فاز ۱ مستقل است.
3. **`app.js`:** R2-a ← C3-b ← N3-a.
4. **`publish.js`:** C1-c ← C1-b2 ← C3-a + C3-c ← N2-a ← C1-a.
5. **سایت عمومی:** R1-bc ← R1-e (۱ daisy، ۲ پوسته، ۳ CSS) ← R1-d (پس از گیت) ← N1-b (فهرست از آرایهٔ قالب‌ها).
6. **CSS داشبورد:** R3-a2 بعد از R2-a، R2-c و R2-d. پیش از هر ریلیز دوباره grep می‌شود.
7. **وابسته به داده:** N1-a فاز ۲ (۴ هفته داده)، C2-a فاز ۲ (تقاضای بازپرداخت)، R1-d (کوئری استفاده).

هر مورد کامیت جدا دارد. هفت مورد به `src/dashboard/http.cjs` دست می‌زنند. تست‌های مسابقه در `tests/mysql-races-check.cjs` بلوک‌های جدا دارند.
