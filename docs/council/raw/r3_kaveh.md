R1-a (بزرگ، نسخهٔ اصلاح‌شده): پوستهٔ عمومی — head + هدر + فوتر یک‌بار، و CSS قدیمی ادغام

مریم و رضا درست می‌گویند: فاز ۲ جابه‌جایی واقعی است و ادعای ۷۰٪ باید ثبت شود. اصلاحات: (۱) جای‌گذاری partial در `static.cjs` قبل از بازنویسی `?v=` و کش `rewrittenBodies` انجام می‌شود. (۲) ترتیب صریح: فاز ۱ فوتر، فاز ۲ هدر، فاز ۳ بلوک `<head>` (همان هفت `<link>` و سه `<script>` که در ۱۴ صفحه تکرار است، حدود ۲KB هر صفحه، این را برای قوی‌تر شدن بزرگ اضافه کردم)، فاز ۴ ادغام CSS و حذف `assets/vazirmatn.woff2` فقط بعد از ریلیز R1-b، چون signature هم آن را می‌خواند. (۳) فهرست سلکتورهای استفاده‌شده/نشده ضمیمهٔ spec می‌شود و فاز ۴ با عکس‌مقایسهٔ `check:ui` در ۳ عرض و روی پربازدیدها (resume-builder، resume-website، blog) تأیید می‌گیرد. (۴) حساب خط: حذف حدود ۴۵۰ خط HTML و ۱۵ خط CSS مینی‌فای (۴۲KB)؛ اضافه حدود ۹۰ خط کد/partial/تست و حدود ۴۰ خط (۱۲KB) قاعدهٔ منتقل‌شده به `info.css`. خالص منفی است. هر فاز جدا ریلیز می‌شود.

R1-b (کوچک): حذف فایل‌های یتیم

درست است: `/signature/` در چهار تست است و `site-content-check` وضعیت ۲۰۰ آن را assert می‌کند. اصلاح: چهار تست (`browser-audit-check`، `full-ui-audit`، `site-interaction-contrast-check`، `site-content-check`) از لیست مسیرها پاک شوند، `signature` در `TAKEN_SLUGS` بماند تا کسی آن نام کاربری را نگیرد، و `/signature/` به ۴۰۴ برسد. سه CSS و PNG بدون تغییر. حدود ۳۰۰ خط و ۲۵۰KB حذف، چهار ویرایش آرایه. این ریلیز باید قبل از فاز ۴ در R1-a برود.

R1-c (کوچک): یک فونت و یک favicon

قبول است. اصلاح: لینک فونت در `auth-ui/css/tokens.css` به `/assets/fonts/Vazirmatn.woff2` برود (rewrite فعلی `?v=` برای مسیر مطلق هم کار می‌کند، طبق نظر مریم)، سپس `check:ui` روی `/login/`، `/register/`، `/forgot-password/` اجرا شود تا فونت واقعاً ۲۰۰ بگیرد. ۱۱۱KB کمتر روی قیف ثبت‌نام؛ یک خط ویرایش، سه favicon بی‌ارجاع حذف.
